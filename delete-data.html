데이터 삭제 안내

DASH — Worklife Dashboard · 개발자: skier-song9 · 문의: 0603paul@gmail.com

요약 — DASH는 개발자의 서버에 사용자 데이터를 저장하지 않습니다. 모든 데이터는 사용자의 기기 안에만 있으므로, 삭제도 기기에서 즉시 이루어집니다. 개발자에게 요청을 보내고 기다릴 필요가 없습니다.

1. 계정 연결만 끊기

연결한 계정의 토큰과 그 계정으로 받아온 데이터만 지웁니다. 앱의 다른 설정은 그대로 남습니다.

  1. DASH를 실행합니다.
  2. 상단 바 오른쪽의 톱니바퀴(⚙︎)를 눌러 설정을 엽니다.
  3. 끊으려는 항목(Claude Code · Codex · Antigravity)에서 연결 해제를 누릅니다.

누르는 즉시 해당 계정의 OAuth 토큰이 기기에서 삭제됩니다.

2. 모든 데이터 삭제하기

앱이 기기에 보관한 것을 남김없이 지웁니다.

  1. Android: 설정 ▸ 애플리케이션 ▸ DASH ▸ 저장공간에서 데이터 삭제를 누르거나, 홈 화면에서 앱을 길게 눌러 제거합니다.
  2. iOS: 홈 화면에서 앱을 길게 눌러 앱 삭제를 선택합니다.

앱을 삭제하면 토큰·설정이 모두 함께 사라집니다.

3. 이전 버전의 Google 계정 권한 철회

버전 1.0.1부터 Gmail 연동 기능은 삭제되었습니다. 그 이전 버전에서 Gmail을 연동했던 경우, 토큰은 기기에만 있었고 업데이트 후 더 이상 사용되지 않지만, Google 계정 쪽 권한을 직접 철회해 두는 것을 권합니다.

  1. Google 계정 ▸ 타사 앱 및 서비스로 이동합니다.
  2. 목록에서 DASH를 선택하고 액세스 권한 삭제를 누릅니다.

4. 삭제되는 데이터와 보관 기간

데이터보관 위치삭제 시점추가 보관
OAuth 토큰 (Claude Code · Codex · Antigravity) 기기 내부 암호화 저장소 연결 해제 또는 앱 삭제 시 즉시 없음
앱 설정 (카드 순서, 표시 모델, 표시 옵션) 기기 내부 앱 삭제 또는 데이터 삭제 시 즉시 없음
D-Day 로컬 데이터 (지역·관심 이벤트·카테고리 순서·접힘 상태, 캐시된 피드 파일, 이미 반응한 이벤트 ID) 기기 내부 앱 삭제 또는 데이터 삭제 시 즉시 없음

개발자는 사용자 데이터를 저장하는 서버를 운영하지 않으므로, 위 항목 외에 별도로 보관되는 개인정보는 없습니다. D-Day 이벤트에 남긴 익명 반응(👍/👎)은 사용자와 연결되는 정보가 전혀 없어, 특정 사용자의 반응만 골라 삭제하는 것은 불가능합니다. 서버의 익명 반응 수는 12개월 후 만료됩니다. 자세한 처리 내용은 개인정보처리방침을 참고하세요.
