What is DASH? // the app's purpose

DASH is a personal productivity dashboard iOS and Android app for developers who use AI coding tools. Developers check the same thing many times a session — "how much AI tool quota do I have left?". DASH's purpose is to move that check onto a phone screen you already own.

  • Shows session, weekly and per-model usage limits of AI coding tools (Claude Code, Codex, Antigravity) as gauges
  • Forecasts when you'll run out at the current pace, and tints the screen edges as quota runs low
  • Stands upcoming holidays, events and calendar items beside the cards as a D-Day timeline
  • A personal tool — no subscription, and no server that stores data that could identify you

Privacy // by design

DASH stores nothing on any server that could identify you.

  • Usage data and calendar events are processed and kept on your device only
  • OAuth tokens are stored encrypted — in the iOS Keychain, and in Android EncryptedSharedPreferences
  • The app talks only to each AI service's usage API, to dash-worklife.org for the holiday and event list, and to the server that counts anonymous reactions
  • Event 👍/👎 reactions are sent anonymously, with no account or device identifiers
  • No ads, no tracking, no analytics SDKs
