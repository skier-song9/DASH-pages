기능 01

사용량 대시보드

Claude Code와 Codex의 한도를 도구별 카드로 나눠 보여줍니다. 창(window)마다 한 줄, 줄마다 눈금 게이지 하나. 숫자를 읽지 않아도 막대 색만 보면 지금 여유가 있는지 알 수 있습니다.

화면 // 도구 하나에 카드 하나

카드 제목은 측정 대상인 도구 이름입니다. 오른쪽 위 범례는 백분율 열이 무엇을 가리키는지 알려줍니다. 한 줄은 창 이름 · 게이지 · 백분율 · 초기화/소진 시각 순서로 읽습니다.

게이지 표시
게이지 표시 방식

Codex

% 사용
1주 25% 5일 2시간 후 초기화

위 토글은 실제로 동작합니다. 앱의 설정 화면에 있는 것과 같은 항목입니다.

  • 눈금 게이지 — 매끈한 막대 대신 30칸으로 끊어 그립니다. 한 칸이 대략 3%라 "얼마나 남았나"를 눈금 수로 셀 수 있습니다.
  • 색 — 남은 양에 따라 초록 → 연두 → 노랑 → 주황 → 연빨강 → 빨강으로 내려갑니다. 숫자를 읽기 전에 색이 먼저 보입니다.
  • 창 이름 — 5시간, 1주처럼 한도가 걸리는 단위 그대로 쓰고, 모델별 한도는 모델 이름(Fable)으로 표시합니다.

사용량 / 잔여량 // 백분율 열을 뒤집기

기본값은 사용량입니다. 쓴 만큼 막대가 차오르고, 차오를수록 빨간색에 가까워집니다. 남은 쪽이 더 자연스럽다면 설정(톱니바퀴)에서 잔여량으로 바꿉니다. 그러면 백분율 열과 막대가 남은 값 기준으로 바뀝니다 — 막대는 똑같이 왼쪽부터 채워지고, 막대가 길다는 것이 곧 "여유가 있다"는 뜻이 됩니다.

위 카드의 토글을 바꾸면 68% ↔ 32%처럼 백분율과 막대 길이가 함께 뒤집힙니다. 색은 어느 쪽 표시에서도 "남은 양" 기준을 유지하므로, 표시를 바꿔도 위험도 판단은 흔들리지 않습니다.

  • 사용량 — 쓴 만큼 채워집니다. 많이 쓸수록 막대가 길어지고 빨간색으로 바뀝니다.
  • 잔여량 — 남은 만큼 채워집니다. 잔여량이 충분하면 길고 초록색, 바닥나면 짧고 빨간색입니다.

예상치 // 지금 속도라면 언제 바닥나는가

게이지에 반투명하게 덧칠된 구간이 예상치입니다. 지금까지의 소비 속도를 그대로 창의 끝까지 밀어 보고, 그 속도로 갔을 때 도달할 지점을 표시합니다. 이 구간은 초기화보다 먼저 소진될 것으로 보일 때만 나타납니다. 여유 있게 끝날 창은 굳이 겁주지 않고, 초기화 시각만 조용히 보여줍니다.

소진이 먼저 오는 경우

지금 속도를 유지하면 초기화 전에 한도를 다 씁니다 → 예상 구간이 나타나고, 오른쪽 글자가 "후 초기화" 대신 "후 소진"으로 바뀌며 빨갛게 표시됩니다.

예상 구간 없음

예상치는 설정에서 끌 수 있습니다. 꺼도 옆의 카운트다운은 그대로 남습니다.

  • 예측이지 약속이 아닙니다. 속도가 바뀌면 예상 지점도 같이 움직입니다.
  • 예상 구간은 반투명하게, 실제 사용량은 불투명하게 그려 측정값과 추정값을 섞지 않습니다.

한눈 경고 // 화면을 보지 않아도 알아채도록

DASH는 옆에 세워 두고 곁눈으로 보는 화면입니다. 그래서 잔여량이 일정 수준 아래로 내려가면 화면 가장자리가 경고색으로 다섯 번 은은하게 빛났다가 사라집니다. 글자를 읽지 않아도, 시야 구석의 색만으로 "슬슬 아껴 써야 한다"를 알 수 있습니다.

기준은 남은 양입니다. 여러 도구·창 가운데 가장 급한 창 하나가 전체 경고 수준을 정합니다.

버튼을 누르면 해당 단계의 경고가 재생됩니다. 앱에서와 같이 다섯 번 깜빡인 뒤 사라집니다.

  • 잔여 50% 이하 — 노란색. 절반을 썼습니다. 알아둘 만하지만 멈출 일은 아닙니다.
  • 잔여 30% 이하 — 주황색. 마지막 3분의 1입니다. 속도 조절을 시작할 때입니다.
  • 잔여 5% 이하 — 빨간색. 사실상 소진입니다.
  • 경고는 가장자리에서 안쪽으로 번지는 빛이라 가운데의 게이지를 가리지 않고, 다섯 번 깜빡인 뒤에는 완전히 사라져 눈을 피로하게 하지 않습니다.
