기능 02

Unread 사이드바

사용량 대시보드 오른쪽에 붙어 있는 세로 패널입니다. 연결한 Gmail 계정마다 안읽은 메일 개수를 보여주고, 그 아래에 지금 봐야 할 메일만 몇 줄 남깁니다. 필요 없을 땐 접어서 화면을 통째로 대시보드에 돌려줍니다.

접고 펴기 // 화면을 뺏지 않는 사이드바

제목 오른쪽 › 를 누르면 사이드바가 접히고, 가장자리에 얇은 띠만 남습니다. 띠의 ‹ 를 누르면 다시 펴집니다. 대시보드는 남은 폭에 맞춰 다시 배치됩니다.

위 사이드바는 실제로 접히고 펴집니다. 톱니바퀴(⚙)를 누르면 계정 설정으로 전환됩니다. 두 버튼 모두 Tab으로 이동해 Enter/Space로 조작할 수 있습니다.

  • 계정 줄 — 색 점, 라벨, 메일 주소, 안읽은 개수. 개수가 0보다 크면 빨갛게 표시됩니다.
  • 메일 줄 — 발신자, 제목 한 줄, 받은 시각. 오른쪽 체크 버튼을 누르면 Gmail에서 바로 읽음 처리됩니다.
  • 접힌 목록 — 계정당 기본 3줄만 보이고, 나머지는 "N개 더 보기"로 펼칩니다.

톱니바퀴 → 계정 설정 // 같은 자리에서 바뀌는 화면

사이드바 제목 옆 톱니바퀴를 누르면 같은 패널이 계정 목록으로 바뀝니다. 새 창이 뜨지 않고, 화면이 다른 곳으로 넘어가지도 않습니다. 톱니바퀴 자리는 뒤로 가기(‹)로 바뀌어 메일 목록으로 돌아올 수 있습니다.

각 계정 줄 오른쪽에는 편집 › 이 붙어 있습니다. 여기를 누르면 그 계정만의 상세 설정 — 라벨, 색, 그리고 주요 메일 기준 — 으로 들어갑니다.

라벨 · 색상 // 계정을 한 눈에 구분하기

메일 주소는 길고 서로 닮아 있습니다. 그래서 계정마다 짧은 라벨과 색 점을 붙입니다. 라벨은 개인 · 직장 · 학교 중에서 고르거나 직접 써 넣을 수 있고, 색은 여덟 가지 중에서 고릅니다. 고르는 즉시 사이드바에 반영됩니다.
