DASH란? // 앱의 목적

DASH는 AI 코딩 도구를 쓰는 개발자를 위한 개인 생산성 대시보드 iOS 앱입니다. 개발자는 하루에도 여러 번 두 가지를 확인합니다 — "AI 도구 사용량이 얼마나 남았지?"와 "놓친 중요한 메일은 없지?". DASH의 목적은 이 두 확인을 앱 하나, 한 화면으로 줄이는 것입니다.

  • AI 코딩 도구(Claude Code, Codex)의 세션·주간 사용 한도를 게이지로 보여줍니다
  • Gmail 안읽은 메일 중 중요한 것만 골라 보여주고, 확인한 메일은 읽음 처리합니다
  • 구독·설치형 서비스가 아닌 개인 도구이며, 별도 서버에 데이터를 저장하지 않습니다

Google 데이터 사용 // 무엇을, 왜

DASH는 아래 목적을 위해서만 Google 계정 연동을 요청합니다.

요청 권한사용 목적
gmail.modify 안읽은 메일의 발신자·제목·요약을 읽어 목록으로 보여주고, 사용자가 확인 표시한 메일을 Gmail에서 읽음 처리하기 위해 필요합니다. 메일을 보내거나 삭제하지 않으며, 읽음 처리 외의 어떤 변경도 하지 않습니다.
openid · email 연결한 계정의 이메일 주소를 확인해 여러 계정을 구분해 표시하기 위해 필요합니다.

메일 데이터는 사용자의 기기에만 보관됩니다. 중요도 분류에는 발신자·제목·본문 일부만 일시적으로 처리되고 어디에도 저장되지 않으며, 광고나 모델 학습에 사용되지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

기능 // 셋 다 한 화면에

▚

사용량 대시보드

Claude Code와 Codex의 세션·주간 한도를 게이지로 표시합니다. 지금 속도라면 언제 소진되는지 예측하고, 리셋 시각을 함께 보여줍니다.

▤

Unread 사이드바

Gmail 안읽은 메일을 규칙과 AI가 함께 분류합니다. 마감·결제·보안처럼 놓치면 잃는 메일만 남기고, 뉴스레터는 조용히 접습니다.

▣

내 기준으로 학습

"노션 알림은 안 중요해" 한 줄이면 분류 기준이 바뀝니다. 자연어 프롬프트가 Gmail 검색 규칙과 의미 기준으로 컴파일됩니다.

프라이버시 // 설계부터

DASH는 서버에 사용자 데이터를 저장하지 않습니다.

  • 메일과 사용량 데이터는 기기 안에서만 처리·보관됩니다
  • OAuth 토큰은 iOS Keychain에 암호화 저장됩니다
  • AI 분류에는 발신자·제목·본문 일부만 전송되며, 어디에도 저장되지 않습니다
  • 광고·트래킹·분석 SDK가 없습니다
