개인정보처리방침

시행일: 2026년 8월 6일 · 문의: 0603paul@gmail.com

DASH(이하 "앱")는 개인 개발자(GitHub: skier-song9, 이하 "개발자")가 제공하는 iOS 애플리케이션입니다. 본 방침은 앱이 어떤 정보를 어떤 목적으로 처리하는지, 그리고 처리하지 않는 것은 무엇인지를 설명합니다.

요약 — 앱은 개발자의 서버에 사용자 데이터를 저장하지 않습니다. 메일과 사용량 데이터는 사용자의 기기 안에서만 처리·보관되며, AI 분류에 필요한 최소한의 메일 정보만 처리 목적에 한해 일시적으로 전송됩니다.

1. 처리하는 정보

항목내용보관 위치
Google 계정 정보 이메일 주소 (openid, email 스코프) 기기 내부
Gmail 데이터 안읽은 메일의 발신자, 제목, 수신 시각, 라벨, 본문 일부(스니펫) — gmail.modify 스코프 기기 내부 (캐시)
OAuth 토큰 Google 계정 및 AI 코딩 도구(Claude Code, Codex) 계정 연결 토큰 iOS Keychain (암호화)
AI 서비스 사용량 Claude Code · Codex의 사용량 한도 및 잔여량 기기 내부

2. 이용 목적

  • 안읽은 메일 목록과 개수를 표시하기 위해 Gmail 메타데이터를 조회합니다.
  • 메일의 중요도를 분류하기 위해 규칙 및 AI 분류를 수행합니다.
  • 사용자가 확인한 메일을 Gmail에서 읽음 처리하기 위해 gmail.modify 권한을 사용합니다. 앱은 메일을 보내거나, 삭제하거나, 읽음 처리 외의 어떤 변경도 하지 않습니다.
  • AI 코딩 도구의 사용량 한도를 표시하기 위해 각 서비스의 사용량 API를 조회합니다.

3. AI 분류를 위한 일시적 전송

메일 중요도 분류를 위해 다음 정보가 개발자가 운영하는 중계 서버(Cloudflare Workers)를 거쳐 외부 LLM(대규모 언어 모델) API로 전송됩니다:

  • 발신자 이름·주소, 제목, 본문 앞부분(최대 220자), 대량발송 여부 등의 신호

이 전송은 분류 응답을 받는 동안에만 존재하는 일시적 처리입니다. 중계 서버는 무상태(stateless)로 어떤 내용도 기록·보관하지 않으며, 개발자가 이용하는 LLM 제공사는 상용 API 약관에 따라 API 입력·출력을 모델 학습에 사용하지 않습니다. 메일 본문 전체나 첨부파일은 전송되지 않습니다.

4. Google 사용자 데이터에 관한 준수 사항 (Limited Use)

앱의 Google API로부터 받은 정보의 사용은 Google API Services User Data Policy의 Limited Use 요구사항을 포함하여 해당 정책을 준수합니다. 구체적으로:

  • Gmail 데이터는 위 2조의 사용자 대면 기능 제공에만 사용합니다.
  • Gmail 데이터를 광고 목적으로 사용하지 않습니다.
  • Gmail 데이터를 제3자에게 판매하거나 양도하지 않습니다.
  • Gmail 데이터를 일반화된(generalized) AI/ML 모델의 개발·개선·학습에 사용하지 않습니다. 3조의 AI 분류는 사용자가 요청한 기능을 제공하기 위한 일시적 처리일 뿐입니다.
  • 사람이 Gmail 데이터를 열람하지 않습니다. 단, 사용자의 명시적 동의가 있는 경우, 보안 목적, 법적 의무 이행의 경우는 예외로 합니다.

5. 저장과 보안

  • 모든 데이터는 사용자의 기기 안에 저장됩니다. 개발자는 사용자 데이터를 저장하는 서버를 운영하지 않습니다.
  • OAuth 토큰은 iOS Keychain에 암호화되어 저장됩니다.
  • 모든 네트워크 통신은 TLS(HTTPS)로 암호화됩니다.
  • 앱에는 광고·트래킹·분석 SDK가 포함되어 있지 않습니다.

6. 제3자 제공 및 처리 위탁

개발자는 사용자 데이터를 제3자에게 제공·판매하지 않습니다. 기능 제공을 위한 처리 위탁은 다음과 같습니다:

수탁자목적내용
Cloudflare, Inc.API 중계분류 요청의 무상태 전달 (저장 없음)
LLM API 제공사메일 중요도 분류3조에 기재된 최소 정보의 일시적 처리

오류 발생 시 개발자에게 전송되는 오류 알림에는 이메일 주소·토큰 등 개인정보가 자동으로 마스킹(redaction)됩니다.

7. 보유 기간 및 삭제

  • 기기 내 데이터는 앱을 삭제하면 함께 삭제됩니다.
  • 앱 설정에서 계정 연결을 해제하면 해당 계정의 토큰과 캐시가 즉시 삭제됩니다.
  • Google 계정 권한은 Google 계정 보안 설정에서 언제든지 직접 철회할 수 있습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 방침의 변경

본 방침이 변경되는 경우 이 페이지를 통해 게시하며, 중요한 변경은 앱 내에서 고지합니다.
